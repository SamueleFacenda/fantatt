# Web (PWA)

Mobile-first React PWA: Vite 8 + React 19 + TypeScript + Tailwind 4 + shadcn/ui,
built hermetically from `package-lock.json` by `nix/web.nix`.

Design tokens in `web/src/styles/` are the executable form of
`docs/09-brandbook.md`; `web/src/lib/api` holds the OpenAPI-generated client.

This directory is a skeleton; the application is built in Phase 3.
